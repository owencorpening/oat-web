Using AI to write an IMDB scraping app

May 6, 2025 · Vectors

← Previous

It can be intimidating to start down the road of using AI to create stuff on your laptop. To start with, you don't have to learn Python, it's favorite language. But you'll have to install it. The AI will gladly tell you how. You will use a terminal, such as the one built in.

As you develop your app, it will begin to require libraries, which you install with "pip install ". You will need to cut paste the answers it gives you into files to run them. Exciting! Especially if you have prior experience programming, this will seem very easy.

I went to first Grok, then chatGpt. Here was my question: could you write a program to: Given: an imdb link to a tv series, and a threshold imdb rating like maybe 6, Find: all the castmembers who subsequently were in another performance that has an imdb rating greater than the threshold

After saving and running their output, pasting it's errors back to it and updating my local file with their updates, it printed this:
