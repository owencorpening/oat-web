Cheatsheets

Free VS Code extension

Keep your own reference notes open while you code. Cheatsheets shows the Markdown and HTML files from a folder you choose in VS Code's secondary sidebar: the list on the left, the sheet on the right. One shortcut shows it and hides it.

What it does

  • Markdown and HTML. Write quick sheets in Markdown, with tables, code blocks, and task lists, or build fully styled reference pages in HTML.
  • Your own folder. Every .md and .html file in the folder appears in the list, sorted by name.
  • Stays current. Add, rename, or edit a file and the panel updates on its own.
  • Checklists that remember. Tick a box and it stays ticked the next time you open the sheet.

Install

The VS Code Marketplace listing is coming soon. Until then you can install it from the source on GitHub by following the README there.

Then open Settings, search for cheatsheets, and set Cheatsheets: Folder to your cheatsheets folder. Press Ctrl+Alt+C (Mac: Ctrl+Cmd+C) to open the panel.

Privacy

Cheatsheets reads files only from the folder you choose. It collects nothing, sends nothing, and has no analytics or network requests of its own. Which boxes you've ticked is kept by VS Code on your own computer.

Support

Found a bug or have a question? Open an issue on GitHub. It's a free side project, so replies may take a few days.
